## 1. 浏览器本地数据

按软件当前实现，收藏、已读记录、深浅色设置、最近搜索（最多 10 条）、更新日志已读状态和反馈草稿保存在当前浏览器；返回时的列表位置、滚动位置和展开状态保存在当前标签页的会话存储中。上述浏览器数据由客户端保存；清除浏览器数据后可能无法恢复，换设备不会自动同步。收藏、已读记录和深浅色设置可在“收藏”页导出和导入。另有 HttpOnly Cookie `mafi_device`：匿名设备标识，仅用于本机阅读偏好（赞/踩）重排，不改变公开采集或全局精选。具体浏览器存储行为以当前版本实现为准。

## 2. 反馈资料

按软件当前实现，通过反馈页提交的文字、选填邮箱、提交时所在页面地址，以及用户选择附上的截图会发送到服务器，用于处理反馈。配置飞书内部群时，反馈可能转发到该群；截图上传至飞书后，应用服务器不再保留该截图。软件还会生成由网络地址和浏览器类别计算的标识，用于反馈限流和封禁滥用来源。

生产环境是否启用飞书转发、相关服务的访问范围，以及反馈资料和标识的实际保存与删除期限，均待运营者核实并在上线前补充；本草案不承诺具体保存期限或第三方服务商安排。

## 4. 来源链接与外部服务

本站展示第三方来源的摘要和链接。点击原文链接后，浏览器会访问对应来源网站，其数据处理适用对方的规则。其他第三方服务（包括反馈转发服务）是否启用及其隐私安排，应由运营者按实际上线配置补充。

当前仅供本人在本机试运行，常态自动模型处理关闭；已按本人授权在隔离环境执行过开发评测。执行 DeepSeek 或 MiniMax API 处理任务时，后端会把待处理的公开资讯及提示词发送至该步骤选用的服务商；MiniMax 使用用户确认的国际开放平台。服务区域、保存策略和实际条款应按实际启用配置核实。本机保存网页和数据库不等于模型推理也在本机。个人持仓、账户、盈亏及身份资料不属于本新闻站采集和发送给模型的范围。

外部数据页由后端请求 AIHOT 公开 Codex 消息接口及 Artificial Analysis 官方模型数据接口，服务商会收到相应网络请求信息；读取已有消息和评测数据不调用本站模型。AIHOT 新闻阅读功能已移除。AA 密钥在本机配置后仅由后端发送给 AA，不交给浏览器；读取结果缓存在本机。这些页面不向数据服务发送个人持仓、账户、盈亏或身份资料。
