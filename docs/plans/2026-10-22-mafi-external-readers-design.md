## 数据与凭据

外部数据不进入业务文章、公开 v1、RSS 或 MCP。后端只访问固定官方 HTTPS 主机，禁重定向和任意地址；AA key 只给后端并只发送给 AA，前端只通过 HTTP 取验证后的数据。示例配置不包含密钥，真实 .env 被 Git 忽略。

AA 读取使用 /api/v2/language/models/free，逐页预留配额，同一轮最多 12 页；完整快照至少间隔 24 小时，一窗口本地最多 100 次请求。无效分页、版本变化、重复 ID 不覆盖成功快照。Tibo 至少间隔十分钟，支持 ETag。冷却和成功快照落本机私有缓存，适用于单 API 进程。

只在可信 SITE_URL 为本机地址时启用，并实际绑定回环端口。响应 private/no-store/noindex，数据不向公网再分发。前台页面每十分钟检查，关闭后没有独立后台通知。
