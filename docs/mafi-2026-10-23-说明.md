## 7. 启动 / 停止自动循环

在仓库根目录：

```powershell
cd <repo>

# 启动（背景 forever；pid 写入 .data/preview-pids.json → autoLoop）
node --env-file=.env scripts/start-mafi-auto.mjs

# 一次性验证
node --env-file=.env scripts/start-mafi-auto.mjs --once

# 停止
node scripts/stop-mafi-auto.mjs
```

| 项 | 说明 |
|---|---|
| 采集 | `scripts/collect-mafi-auto.mjs`，约 10m |
| 分析/精选 | `scripts/analyze-mafi-auto.mjs`，约 60m |
| 调度器 | `scripts/mafi-auto-loop.mjs` |
| 每 tick 上限 | 最多 12 篇 analyze；约 80 llm；最多 12 篇免费 extract（不碰 jina） |
| 日志 | `.data/logs/auto-loop-YYYY-MM-DD.log`、`collect-*.log`、`analyze-*.log`、`analyze-last.json` |

采集子进程会强制 `MODEL_CALLS_ENABLED=false`，不调 LLM。**不要 commit `.env`**。
